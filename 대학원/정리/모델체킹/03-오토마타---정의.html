03 오토마타 - 정의

03 오토마타 - 정의

2026년 10월 14일5 min read

  • topic/formal-methods

Automata

A = \langle Q,E,T,q_0,l\rangle \

는 상태 전이 시스템(State Transition System) 또는 라벨이 있는 전이 시스템(Labeled Transition System, LTS)을 표현하는 형태입니다.

모델 체킹(Model Checking)에서는 시스템의 상태, 상태 간 전이, 각 상태에서 성립하는 명제를 정의하는 데 사용합니다.

각 구성 요소 설명

기호명칭의미
(A)Automaton전체 시스템 모델
(Q)States시스템이 가질 수 있는 상태의 집합
(E)Transition Labels상태 전이를 발생시키는 행동이나 이벤트의 집합
(T)Transition Relation어떤 상태에서 어떤 행동으로 다른 상태에 도달하는지 정의
(q_0)Initial State시스템이 시작하는 초기 상태
(l)Labeling Function각 상태에서 참인 원자 명제들의 집합을 반환하는 함수

Labeling Function

가장 중요한 부분입니다.

먼저 원자 명제(Atomic Proposition) 란 더 이상 분해하지 않고 참 또는 거짓으로 판단하는 기본 논리 명제입니다.

예를 들어,

AP={running,finished,failed}

각 원자 명제의 뜻은 다음과 같습니다.

  • running: 작업이 실행 중이다.
  • finished: 작업이 성공적으로 완료되었다.
  • failed: 작업이 실패했다.

라벨링 함수는

l:Q→2AP

로 정의하며, 각 상태에서 참인 원자 명제를 반환합니다.

상태(l(q))의미
(q_0) 대기∅세 명제 모두 거짓
(q_1) 실행 중(q_2) 성공{finished}finished만 참
(q_3) 실패{failed}failed만 참

예를 들어,

l(q1​)={running}

이라면 (q_1)에서는 running이 참이고 finished, failed는 거짓입니다.

Execution (실행)

전이 시스템(Transition System)에서 Execution은 초기 상태에서 시작하여 전이 관계를 따라 진행되는 상태들의 시퀀스(sequence)이다.

전이 시스템을 다음과 같이 정의하자.

A=(Q,E,T,q0​,l)

Execution은 다음과 같이 표현한다.

q0​e1​​q1​e2​​q2​e3​​⋯

여기서 ((qi​,ei+1​,qi+1​)∈T 이다.

Partial Execution (부분 실행)

  • 초기 상태 (q_0)에서 시작하는 유한한 실행 경로
  • 마지막 상태에서 더 이상 전이가 불가능할 필요는 없음
  • 즉, 실행이 중간에 끝나도 됨

예시:

q0​a​q1​b​q2​

q2​에서 다른 상태로 전이할 수 있어도 부분 실행에 해당한다.

Complete Execution (완전 실행)

더 이상 연장할 수 없는 실행(maximal execution)을 의미한다.

다음 두 가지 경우가 있다.

  1. 무한 실행(Infinite Execution): 전이가 무한히 계속됨
  2. 유한 실행(Finite Execution): 마지막 상태에서 더 이상 전이가 불가능함(Deadlock 또는 Terminal State)

예시:

q0​→q1​→q2​→q3​

q3​에서 가능한 전이가 없다면 Complete Execution이다.

반면 다음처럼 무한히 반복되는 경우도 Complete Execution이다.

q0​→q1​→q2​→q1​→⋯

Reachable State (도달 가능한 상태)

초기 상태 (q_0)에서 0번 이상의 전이를 통해 도달할 수 있는 상태를 의미한다.

수학적으로는 다음과 같다.

Reach(A)={q∈Q∣q0​∗​q}

  • ∗​: 0번 이상의 전이
  • q0​: 초기 상태이며 항상 Reachable
  • Reach(A)⊆Q
